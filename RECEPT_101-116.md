## Kvalitetskontroll

- Första 100 receptdata är oförändrade jämfört med den bevarade HTML-filen.
- De nya recepten innehåller ingredienser, steg, källor, svenska inköpsråd och uppskattade näringsvärden.
- Recepten är redaktionellt sammanställda och har inte provlagats separat.
- Testerna ska köras med `npm run test:data`, `npm run test:logic`, `npm run test:static`, därefter `npm run test:all` i en miljö med npm-åtkomst.
- Ingen publicering har gjorts.
