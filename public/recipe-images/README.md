# Receptbilder

Denna mapp innehåller färdiga lokala **WebP-bilder** för Receptarkivet.

Lägg upp filerna som `<recipe-id>-card.webp` (640×480) och `<recipe-id>-hero.webp` (1200×800).
Bildindexet genereras automatiskt vid GitHub Pages-bygget. Appen visar bara
kompletta bilder som finns i godkännandelistan i
`scripts/generate-recipe-image-index.mjs`.

**Nuvarande preliminärt godkända recept:** Fläskfilégryta med champinjoner,
Key Lime Pie, Tiramisu och Broccolisoppa med cheddar. De övriga sex bildpiloterna
kräver ny granskning och ska inte publiceras än.

Spara inte skyddat material från andra receptsajter i denna mapp.
Alla bilder i piloten är AI-genererade och märks som illustrationer i appen.
